# PSP HEN
PSPHEN is a WIP fork of ARK-4 for the Sony PSP. It is designed to provide a homebrew environment for the PSP, allowing users to run unsigned code and homebrew applications.

# Features
- Homebrew support: Run unsigned code and homebrew applications on your PSP.
- Easy installation: Simple installation process to get started quickly.
- Compatibility: Works with a wide range of PSP models and firmware versions.
- ISO Loader: Load and play ISO games directly from your memory stick.
- UMD Dumper: Dump your own UMD discs so you can use the ISO Loader.
